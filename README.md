# Wpizza Documentation

**Wpizza — Token Creation, Fair Launches, Bonding Curves & Token Infrastructure on BNB Smart Chain**

Wpizza is an on-chain token launch and management platform built for the BNB Smart Chain ecosystem.

The documentation provides developers, builders, token creators, and ecosystem participants with the technical information required to understand how Wpizza works, integrate with its contracts, and build on top of its infrastructure.

## What is Wpizza?

Wpizza brings multiple stages of the token lifecycle into a single on-chain ecosystem:

* **Token creation**
* **Fair launches**
* **Bonding-curve markets**
* **Presales**
* **Token trading**
* **Liquidity management**
* **PancakeSwap integration**
* **Token and LP locking**

The goal is simple: make launching and interacting with tokens on BNB Smart Chain easier, more transparent, and more accessible.

Wpizza prioritizes **bonding-curve based launches**, allowing tokens to begin trading through an on-chain price-discovery mechanism before transitioning toward open-market liquidity.

## Why Wpizza on BNB Smart Chain?

BNB Smart Chain provides an EVM-compatible environment with relatively low transaction costs and fast execution, making it well suited for applications that require frequent on-chain interactions.

Wpizza is designed specifically around this environment.

Instead of building another isolated token launch platform, Wpizza aims to contribute infrastructure that makes the BNB Smart Chain token ecosystem easier to use and easier to build on.

### Our contribution to the BNB Smart Chain ecosystem

Wpizza brings:

**1. Easier token creation**

Creators can deploy and configure tokens without having to build their own complete token infrastructure from scratch.

**2. Bonding-curve based price discovery**

Wpizza prioritizes bonding curves as a mechanism for launching and trading tokens before traditional AMM liquidity. This creates an on-chain market from the beginning of the token lifecycle.

**3. Fairer token launches**

The launch process is designed around transparent on-chain rules rather than relying entirely on centralized allocation mechanisms.

**4. A complete token lifecycle**

Wpizza connects token creation, launch, trading, liquidity, and locking into one ecosystem instead of forcing builders to assemble multiple independent systems.

**5. Developer infrastructure**

The protocol exposes smart-contract infrastructure that developers can interact with and build upon, helping create additional applications and tools around BNB Smart Chain tokens.

## Built for Builders

Wpizza is not only a frontend application.

The protocol is designed as infrastructure that can be integrated into other applications, interfaces, and services.

Developers can use the documentation to understand the contracts, their interactions, and the lifecycle of tokens launched through Wpizza.

The long-term objective is to make token infrastructure on BNB Smart Chain more composable and easier to access.

## The Wpizza Token Lifecycle

```text
Create Token
     ↓
Launch / Presale
     ↓
Bonding Curve
     ↓
On-Chain Trading
     ↓
Target Reached
     ↓
Liquidity Migration
     ↓
PancakeSwap
     ↓
Liquidity Lock
```

This architecture allows a token to move through its lifecycle while remaining connected to transparent on-chain infrastructure.
