## How they connect

`WpizzaFactory` clones `WpizzaPair` from the implementation above. Each market is a clone, not a new deploy of the full pair bytecode.

`createPair(PairCreationParams)` on the factory is the only way to open a curve market. The clone salt is:

```solidity
keccak256(abi.encodePacked(projectToken, paymentToken, block.chainid))
```

`WpizzaRouterV2` is pointed at that factory. It seeds virtual liquidity (`addLiquidity` with project + virtual tokens) and routes buys and sells. It does not create pairs and it does not remove liquidity.

The factory must have `wPizzaV2Router` and `wPizzaLock` set before a market can open. Lock address is on the [token factory](/contracts/wpizza-token-factory-contrats) page.

## What to call

| You want | Call |
| -------- | ---- |
| Open a Pizza Curve market | Factory `createPair(PairCreationParams)` |
| Buy / sell | Router swap functions |
| Read reserves | Pair `getReserves()` and `getRealReserve()` |
| Read trades | Pair `getTrades()` / `getLatestTrades()` |

Do not send tokens straight into a pair and expect a mint. Use the router.
