## Token types

New tokens are clones of `token1`–`token6`.

| `tokenType` | Implementation | Behavior |
| ----------- | -------------- | -------- |
| `1` | token1 | Tax-free, fixed supply |
| `2` | token2 | Mintable |
| `3` | token3 | Burnable |
| `4` | token4 | Pausable |
| `5` | token5 | Tax |
| `6` | token6 | Tax + mint / burn / pause flags |

Salt for a clone:

```solidity
keccak256(abi.encode(msg.sender, name, symbol, tokenType, createdTokenCount[creator]))
```

`predictNextTokenAddress` on the factory uses the same salt.

## Factory entry points

| Function | Use |
| -------- | --- |
| `createToken` | Token + Pancake pair (no LP) |
| `createTokenWithNoPair` | Token only (Pizza Curve uses this) |
| `launch` | Create token and add LP |
| `openMarket` | Existing token + existing pair, add LP |
| `launchToken` | Existing token, create pair if needed, add LP |
| `createPresale` | Clone the presale implementation and run the first buy |

PancakeSwap V2 router used by the token factory:

`0x10ED43C718714eb63d5aA57B78B54704E256024E`
