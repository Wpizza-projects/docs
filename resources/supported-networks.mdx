# Supported networks

WPizza is live on **BNB Smart Chain**. Other networks are planned.

## Live

| Network | Chain ID | Explorer | Status |
| ------- | -------- | -------- | ------ |
| BNB Smart Chain | `56` | [BscScan](https://bscscan.com) | Live |

App: [wpizza.fun](https://wpizza.fun)

Core contracts on BSC are listed on [WPizzaDex contracts](/contracts/wpizza-dex-contracts) and [Token factory contracts](/contracts/wpizza-token-factory-contrats).

## Coming next

| Network | Status |
| ------- | ------ |
| Robinhood chain | Planned |

More EVM networks will follow the same product surface: token factory, Pizza Curve, presale, and lock.

## What this means for you

Until a second network is announced as live:

- create and trade only on BSC
- use BNB or BSC ERC-20s as payment tokens
- PancakeSwap V2 is the graduation venue
- explorers and listing links use BscScan / BSC pair addresses
